# Kirinuki

YouTube のライブ配信・アーカイブから、面白い場面を自動で見つけて字幕付きの
切り抜き動画（ショート動画）を作るアプリです。動画を入れてボタンを押していくだけで、

**動画のダウンロード → 文字起こし → 切り抜き箇所の提案 → 字幕付き動画の書き出し**

までを 1 つの画面で行えます。


## できること

- 文字起こし（音声 → テキスト）を自動で実行
- AI がライブチャットの盛り上がりなども参考にしながら「切り抜きポイント」を提案
- ショート動画風の字幕を自動で焼き込み
- 縦動画は「人物中心にクロップ」「全体映像＋顔カメラの二段構成」の 2 パターンに対応
- 書き出し前に静止画を見ながらクリップの表示範囲を自分の目で調整できる
- そのまま投稿できる完成動画（字幕焼き込み済み）と、Premiere Pro などで自分で編集したい人向けの
  「字幕なし素材＋字幕ファイル」のどちらも書き出せる

## 起動方法

1. インストーラー（`KirinukiSetup.exe`）を実行してインストールします。
2. デスクトップまたはスタートメニューの「Kirinuki」を起動すると、タスクトレイに常駐アイコンが現れ、
   自動でブラウザが開きます（開かない場合はトレイアイコンを右クリック →
   「🌐 Web画面（ブラウザ）を開く」）。
3. API キー（文字起こし・AI提案に使用）はインストーラー版では最初から設定済みのため、
   通常は何も設定せずにそのまま使い始められます。エラーが出た場合のみ、画面右上の
   「⚙ 設定」から自分の API キーを入力してください。

作業が終わったら、トレイアイコンの「❌ Kirinuki サーバーを終了する」でアプリを終了できます。

### ① ダウンロード

YouTube の URL を入力すると、動画本体とライブチャットのログを取得します。

> **💡 おすすめの取得方法**
>
> 自分（または管理しているチャンネル）の配信の場合は、アプリの「▶ ダウンロード」で直接落とすより、
> **YouTube Studio から元の動画ファイルをダウンロードして、②文字起こしの画面にアップロードする方法がおすすめです。**
> YouTube 側のダウンロード対策により、アプリからの直接ダウンロードは失敗したり、配信時に圧縮された
> 画質になってしまうことがあるためです。
>
> この方法を使う場合、アプリ側では動画そのものはダウンロードせず、
> **「💬 チャットのみ DL」ボタンでライブチャットのログだけ取得すれば十分です。**
> チャットログは③の切り抜き提案で「どこが盛り上がったか」の参考情報として使われます。

- 「▶ ダウンロード」：動画（画質は 1080p / 720p から選択）とチャットの両方を取得します。
- 「💬 チャットのみ DL」：動画は取得せず、チャットログだけ取得します（上記のおすすめの使い方）。
- ダウンロードに失敗する場合（年齢制限・メンバー限定動画、ボット判定など）は、トレイメニューの
  「🍪 Cookieの手動保存手順を見る」の案内に沿って Cookie を保存すると解決することがあります。

<!-- 画像: ①ダウンロード画面 -->

### ② 文字起こし

動画・音声ファイルをテキスト化します。

- ①でダウンロードしたファイルは自動的に一覧に表示されます。YouTube Studio から自分でダウンロードした
  動画ファイルを使う場合は、ここの枠に直接ドラッグ＆ドロップ、またはクリックして選択してください
  （mp4 / flac / mp3 / wav / mov / mkv 対応）。
- 文字起こしの範囲を分単位で指定することもできます（長時間配信の一部分だけ試したいときに便利です）。
- 「▶ 文字起こし」を押すと処理が始まります。長時間の動画ほど時間がかかります。

<!-- 画像: ②文字起こし画面（ドラッグ＆ドロップ） -->

### ③ 切り抜き提案

文字起こし結果（と、あれば②で取得したチャットログ）をもとに、AI が面白い場面を自動で提案します。

- 「追加指示」欄に「〇〇について話している部分を切り抜いて」のように条件を書くと、それを最優先で
  反映してくれます。
- 「無音区間をカット」をオンにすると、間延びした無音部分を自動でカットしてテンポを整えます。
- 「▶ 提案を生成」を押すと、切り抜き候補のクリップ一覧が作成されます。

<!-- 画像: ③切り抜き提案画面 -->

### ④ レンダリング

ここが一番重要なステップです。③で作った候補から動画ファイルを作ります。

まず動画・文字起こし・クリップ提案ファイルを選んで「クリップを読み込む」を押すと、候補クリップが
カード形式で並びます。カードごとに以下を確認・調整してください。

<!-- 画像: ④クリップカード一覧 -->

#### 表示範囲は必ず調整する

自動提案の枠のままだと、人物が画面からはみ出たり、字幕と顔が重なったりすることがあります。
書き出す前に、各クリップの **「🎯 静止画から切り抜き範囲を指定」** ボタンを必ず押して、
実際の静止画を見ながら映る範囲・ズームを自分の目で確認・調整してください。

- 静止画の上にドラッグして枠を指定すると、その枠が収まる位置・ズームに自動で計算されます。
- 「二段構成」モードのクリップは「上段（全体映像）」「下段（顔カメラ）」をタブで切り替えてそれぞれ指定します。
  「クロップ」モードのクリップは表示範囲 1 箇所だけ指定します。
- 「すべてのクリップに適用」にチェックしておくと、同じモードの他のクリップにもまとめて反映できます。

<img width="974" height="688" alt="image" src="https://github.com/user-attachments/assets/4118afee-b5b0-4370-b7dd-293ba9074073" />


#### Studio で字幕などを細かく修正する

自動生成のままだと字幕の改行や表示位置が気になる場合は、「🎬 Studio で確認・反映」ボタンから
Remotion Studio を開いて、そこで直接修正できます。表示範囲や字幕サイズなどをアプリ側（静止画からの
範囲指定や「⚙ 全クリップ共通設定」）で直した場合も、もう一度このボタンを押せば最新の内容が Studio
に反映されます。修正のしかたと、修正後の書き出し方法（Studio自身のRender機能を使います）は下の
「Remotion Studio の使い方」を参照してください。

<img width="864" height="264" alt="image" src="https://github.com/user-attachments/assets/db996162-9988-4541-ab8c-0c0f43e7d60c" />


#### 「編集用に書き出し」か「レンダリング」かを選ぶ

表示範囲などの調整が済んだら、目的に応じて選びます（Studio で直接修正して書き出した場合は、
このどちらのボタンも押す必要はありません）。

- **プレミアプロ（Premiere Pro）などの編集ソフトで自分で字幕や演出を付けたい場合**
  → 「📦 編集用に書き出し」を選びます。指定した表示範囲・カットが反映済みで、字幕やタイトルバーは
  焼き込まれていない mp4 と、タイミングが一致した字幕ファイル（SRT）が ZIP でダウンロードできます。
  Premiere Pro などに mp4 をドラッグ＆ドロップし、SRT を読み込んで字幕として使ってください。
- **このアプリの字幕・演出付きのまま、修正なしでそのまま投稿できる動画がほしい場合**
  → 「▶ レンダリング」を選びます。字幕・タイトルバー・演出まですべて焼き込んだ完成 mp4 が作られます。

出来上がった動画は一覧からダウンロードできます（Studio から書き出した場合を除く。保存先は次章参照）。

<!-- 画像: 編集用に書き出し / レンダリング 結果 -->

### ⑤ クリップ結合

④で作った複数のクリップを 1 本の動画につなげたいときに使います。つなげたい順にクリップを追加し
（ドラッグで順序を入れ替え可能）、「▶ 結合実行」を押すと 1 本の動画に結合されます。

## Remotion Studio の使い方

Remotion Studio は、このアプリが動画を作るのに使っている描画エンジンの編集・プレビュー画面です。
アプリのクリップカードはあくまで簡易的な見た目なので、本番と全く同じ映像を見ながら、字幕のタイミング
やフレーム単位の位置ズレなど、アプリの操作だけでは直しきれない細かい部分を直接修正できます。
<img width="1713" height="1253" alt="スクリーンショット 2026-07-27 004650" src="https://github.com/user-attachments/assets/ee782af2-a32a-4d25-9ff0-401870ec49c1" />

1. ④レンダリングの画面で確認したいクリップにチェックを入れ、「🎬 Studio で確認・反映」を押します。
2. 準備ができると通知バナーが表示されるので、「🚀 Studio を開く」から新しいタブで開きます。
3. 画面左側に、選んだクリップが一覧で並びます（複数選んでいれば複数並びます）。クリックすると
   そのクリップのプレビューに切り替わります。
4. 中央のプレビュー画面で再生・一時停止ができ、下部のタイムラインバーをクリック／ドラッグすると
   好きな位置に飛べます。マウスホイールで拡大縮小、ドラッグで表示位置の移動もできます。
5. 字幕の表示位置やタイミングなどが気になる場合は、プレビュー上の要素を直接ドラッグしたり、
   タイムライン上のバーをドラッグしてタイミングを調整します。
6. 修正できたら、Studio 側の **Render（書き出し）機能を使ってそのクリップを直接レンダリングします**。
   アプリの「▶ レンダリング」ボタンは押さなくても、この書き出しだけで動画が完成します。

> **🔄 アプリ側で直したら、もう一度「🎬 Studio で確認・反映」を押してください。**
> 位置ピッカーや「⚙ 全クリップ共通設定」など、アプリ側でクリップの設定を変更しても、すでに開いている
> Studio タブには自動的には反映されません。修正のたびに「🎬 Studio で確認・反映」を押し直して、
> Studio 側の内容を最新の状態にしてから確認・Render してください。

> **⚠ 修正は必ず Render まで行ってから閉じてください。**
> Studio 上での修正は、その場で Render して書き出すまでは保存されません。書き出さずにタブを閉じたり、
> アプリ側で「🎬 Studio で確認・反映」をもう一度押したりすると、変更は破棄されてアプリ側の最新の内容に
> リセットされます（誤操作でアプリ側の設定を壊さないための安全設計です）。

> **📁 Studio から書き出した動画の保存先**
> Studio の Render 機能で書き出した動画は、アプリの「▶ レンダリング」「📦 編集用に書き出し」とは
> 別の場所（`remotion/out` フォルダ）に保存されます。アプリのクリップ一覧には出てこないので、
> タスクトレイの「🎬 Remotion（動画出力先）を開く」からフォルダを開いて取り出してください。

## データの保存場所

作成したファイルはインストールフォルダの近くに保存されます（トレイメニューの
「📂 インストールフォルダを開く」からすぐに開けます）。

| フォルダ | 内容 |
|---|---|
| `downloads/` | ダウンロードした動画・チャットログ |
| `transcriptions/` | 文字起こし結果・切り抜き提案 |
| `clips/` | 「▶ レンダリング」で作った完成動画 |
| `exports/` | 「📦 編集用に書き出し」の ZIP（mp4 + SRT） |
| `remotion/out/` | Remotion Studio の Render 機能で書き出した動画（トレイの「🎬 Remotion（動画出力先）を開く」） |
